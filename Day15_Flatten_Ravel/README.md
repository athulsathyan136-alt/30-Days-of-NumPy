# Day 15 — NumPy Flattening and Ravel

## Overview
Learn how to convert multidimensional NumPy arrays into one-dimensional arrays.

## Topics
- `flatten()`
- `ravel()`
- One-dimensional and two-dimensional arrays
- Array shapes
- Copy versus view

## Files
- `flatten_ravel.py` — Examples
- `exercises.py` — Practice exercises

## Run
```bash
python flatten_ravel.py
python exercises.py
```

## Applications
Flattening is useful when preparing arrays for machine learning, feature processing, and numerical analysis.
