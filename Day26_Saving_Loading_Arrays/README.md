# Day 26 – Saving and Loading NumPy Arrays

## Overview
Learn how to save NumPy arrays to files and load them back into Python.

## Concepts Covered
- Saving arrays with `np.save()`
- Loading arrays with `np.load()`
- Saving multiple arrays with `np.savez()`
- Understanding `.npy` files
- Understanding `.npz` files

## Project Structure


## Run the Programs

```bash
python saving_loading.py
python exercises.py
```

## Key Learning

- `.npy` stores a single NumPy array.
- `.npz` stores multiple named NumPy arrays.
- `np.load()` retrieves saved array data.
