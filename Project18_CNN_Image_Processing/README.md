
# Project 18 - CNN Image Processing Using NumPy

## Description
A CNN-style image feature extraction system built
using Python and NumPy.

## Features
- Synthetic image generation
- Convolution operations
- Vertical and horizontal edge detection
- ReLU activation
- Max pooling
- Feature extraction
- Basic filter-response classification
- NumPy output storage

## Technologies
- Python
- NumPy

## Installation
pip install -r requirements.txt

## Run
python main.py

## Outputs
- extracted_features.npy
- filter_scores.npy

## Note
This is an educational CNN feature extraction
demonstration, not a trained deep learning model.
