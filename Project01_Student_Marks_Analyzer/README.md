
# Student Marks Analyzer

A beginner-friendly data analysis project using Python and NumPy.

## Project Overview

This project analyzes marks from five students across four subjects.

It calculates student totals, averages, subject averages, highest and lowest marks, and identifies students' low-scoring subjects.

## Technologies

- Python
- NumPy

## Dataset

| Student | Python | Math | ML | SQL |
|---|---:|---:|---:|---:|
| Student 1 | 85 | 78 | 92 | 80 |
| Student 2 | 65 | 70 | 75 | 68 |
| Student 3 | 90 | 95 | 88 | 92 |
| Student 4 | 35 | 45 | 50 | 38 |
| Student 5 | 72 | 80 | 69 | 75 |

## Features

1. Create a NumPy marks array.
2. Calculate student totals.
3. Calculate student averages.
4. Calculate subject averages.
5. Find maximum and minimum marks.
6. Identify the top-performing student.
7. Detect marks below 40.
