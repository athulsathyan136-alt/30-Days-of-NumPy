
# Project 19 - Transformer From Scratch Using NumPy

## Description
An educational Transformer-style forward-pass implementation
using Python and NumPy.

## Features
- Tokenization
- Token embeddings
- Positional encoding
- Query, Key and Value projections
- Scaled dot-product attention
- Causal masking
- Multi-head self-attention
- Residual connections
- Layer normalization
- Feed-forward network
- Next-token probability calculation

## Technologies
- Python
- NumPy

## Installation
pip install -r requirements.txt

## Run
python main.py

## Output
outputs/transformer_results.npz

## Note
This is an untrained educational implementation.
It does not generate meaningful language or reproduce
a complete GPT model.
