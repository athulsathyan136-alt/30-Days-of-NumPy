
# Project 12 - Employee Workforce Analytics

## Description
An employee analytics system developed using Python and NumPy.

## Features
- Salary analysis
- Department-wise comparisons
- Employee performance analysis
- Promotion eligibility detection
- Salary percentile analysis
- Experience and salary correlation
- Employee ranking
- Automatic CSV report generation

## NumPy Functions
genfromtxt, mean, median, std, min, max,
percentile, unique, isin, where, select,
argmax, argsort, corrcoef, column_stack,
savetxt

## Technologies
- Python
- NumPy

## Installation
pip install -r requirements.txt

## Run
python main.py

## Output
- employee_report.csv
- department_report.csv
