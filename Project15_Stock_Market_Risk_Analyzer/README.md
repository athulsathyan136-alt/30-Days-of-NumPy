
# Project 15 - Stock Market Risk Analyzer

## Description
A fictional stock market and portfolio analysis
system built using Python and NumPy.

## Features
- Stock price analysis
- Daily price changes
- Percentage returns
- Average return calculation
- Volatility analysis
- Best and worst stock identification
- Correlation matrix
- Weighted portfolio return
- Portfolio volatility
- Return percentile analysis
- CSV report generation

## Technologies
- Python
- NumPy

## Installation
pip install -r requirements.txt

## Run
python main.py

## Outputs
- outputs/stock_analysis.csv
- outputs/portfolio_returns.csv

## Disclaimer
Uses fictional data for educational purposes.
Not investment advice.
