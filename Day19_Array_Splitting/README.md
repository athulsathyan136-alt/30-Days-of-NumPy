# Day 19 — NumPy Array Splitting

## Overview
Learn how to divide NumPy arrays into smaller arrays using `np.split()`.

## Topics
- `np.split()`
- Accessing split arrays with indexing
- Equal-sized sections
- `np.array_split()` for unequal sections

## Files
- `splitting.py` — Examples
- `exercises.py` — Practice exercises

## Run
```bash
python splitting.py
python exercises.py
```

## Applications
Array splitting is useful for dividing datasets into smaller batches and organizing numerical data.
