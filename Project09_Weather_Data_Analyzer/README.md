
# Project 09 - Weather Data Analyzer

## Description
A weather data analysis project using NumPy.

## Features
- Temperature analysis
- Humidity analysis
- Rainfall analysis
- Hottest and coldest day detection
- Rainy day counting
- Automatic report generation

## NumPy Functions
- array()
- genfromtxt()
- mean()
- median()
- max()
- min()
- argmax()
- argmin()
- sum()
- count_nonzero()
- savetxt()

## Technologies
- Python
- NumPy

## How to Run

Install dependencies:

pip install -r requirements.txt

Run:

python main.py

## Output
The analysis report is saved in the outputs folder.
