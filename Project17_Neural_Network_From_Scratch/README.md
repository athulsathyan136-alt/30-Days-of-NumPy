
# Project 17 - Neural Network From Scratch

## Description
A simple binary classification neural network
built from scratch using Python and NumPy.

## Features
- Forward propagation
- ReLU activation
- Sigmoid activation
- Binary cross-entropy loss
- Backpropagation
- Gradient descent
- Model parameter saving
- Prediction report generation

## Architecture
- Input layer: 3 neurons
- Hidden layer: 4 neurons
- Output layer: 1 neuron

## Technologies
- Python
- NumPy

## Installation
pip install -r requirements.txt

## Run
python main.py

## Outputs
- neural_network_model.npz
- predictions.csv

## Disclaimer
Educational implementation. Evaluation on training
data does not establish generalization performance.
