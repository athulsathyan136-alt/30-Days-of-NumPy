# Day 14 — NumPy Array Reshaping

## Overview
Learn how to change the dimensions of NumPy arrays while preserving their values.

## Topics
- `reshape()`
- One-dimensional and two-dimensional arrays
- The `shape` attribute
- Rows and columns
- Element-count requirements

## Files
- `reshaping.py` — Examples
- `exercises.py` — Practice exercises

## Run
```bash
python reshaping.py
python exercises.py
```

## Applications
Reshaping is useful for organizing data for machine learning, image processing, and numerical analysis.
