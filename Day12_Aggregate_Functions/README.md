# Day 12 — NumPy Aggregate Functions

## Overview
Learn to summarize numerical data using NumPy aggregate functions.

## Topics
- `np.sum()` — Total
- `np.mean()` — Average
- `np.min()` — Minimum value
- `np.max()` — Maximum value
- `np.std()` — Standard deviation
- Range — Difference between maximum and minimum

## Files
- `statistics.py` — Examples of aggregate functions
- `exercises.py` — Practice exercises

## Run
```bash
python statistics.py
python exercises.py
```

## Applications
These functions are useful for analyzing student marks, datasets, measurements, and machine learning data.
