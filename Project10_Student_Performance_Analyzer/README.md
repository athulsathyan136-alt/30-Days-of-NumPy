
# Project 10 - Student Performance Analyzer

## Description
An academic analytics project built using Python and NumPy.

## Features
- Student performance analysis
- Subject-wise averages
- Student ranking
- Pass/fail detection
- Grade distribution
- Percentile analysis
- CSV report generation

## NumPy Functions
array, genfromtxt, mean, median, std, argmax,
argmin, where, argsort, percentile, unique,
count_nonzero, column_stack, savetxt

## Installation
pip install -r requirements.txt

## Run
python main.py

## Output
outputs/student_report.csv
