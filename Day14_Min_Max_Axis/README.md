# Day 14 — NumPy Min, Max and Axis

## Overview
Learn to find minimum, maximum, and average values in numerical arrays.

## Topics
- `np.min()`
- `np.max()`
- `np.mean()`
- Row-wise calculations using `axis=1`
- Column-wise calculations using `axis=0`

## Files
- `min_max.py` — Examples
- `exercises.py` — Practice exercises

## Run
```bash
python min_max.py
python exercises.py
```

## Applications
Useful for analyzing temperatures, energy consumption, sales, and machine learning datasets.
