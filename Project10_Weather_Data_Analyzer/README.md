
# Project 10 – Weather Data Analyzer

## Overview
A weather data analysis project developed using Python and NumPy.

It analyzes temperature, rainfall, humidity, and wind speed.

## Features
- Temperature statistics
- Rainfall analysis
- Humidity analysis
- Wind speed analysis
- Hot, moderate, and cool day classification
- Weekly averages
- Percentile calculations
- IQR-based outlier detection
- Automatic CSV and text reports

## Technologies
- Python
- NumPy
- CSV

## How to Run

Install dependencies:

    python -m pip install -r requirements.txt

Run:

    python weather_analyzer.py
