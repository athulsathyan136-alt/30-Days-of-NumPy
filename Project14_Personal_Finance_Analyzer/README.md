
# Project 14 - Personal Finance & Budget Analyzer

## Description
A personal finance analysis system built using Python and NumPy.

## Features
- Total and average expense calculation
- Category-wise expense analysis
- Monthly savings calculation
- Budget comparison
- Overspending detection
- Expense ranking
- Percentage contribution
- CSV financial report generation

## Technologies
- Python
- NumPy

## NumPy Functions
genfromtxt, array, sum, mean, median, max, min,
argmax, argmin, unique, where, sort, argsort,
column_stack, savetxt

## Installation
pip install -r requirements.txt

## Run
python main.py

## Output
outputs/financial_report.csv
