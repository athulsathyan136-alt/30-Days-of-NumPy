
# Project 11 - E-Commerce Sales Analyzer

## Description
A sales analytics project built using Python and NumPy.

## Features
- Total revenue calculation
- Average and median order value
- Product analysis
- Category-wise revenue
- High-value order detection
- Product ranking
- CSV report generation

## NumPy Functions
genfromtxt, array, sum, mean, median, max,
min, argmax, argmin, unique, isin, where,
argsort, std, column_stack, savetxt

## Installation
pip install -r requirements.txt

## Run
python main.py

## Output
outputs/sales_report.csv
