
# Student Marks Analyzer

A beginner-friendly Python project using NumPy to analyze student examination marks.

## Features
- Display student names and marks
- Calculate average, median, highest, and lowest marks
- Identify passing and failing students
- Find high scorers
- Filter marks within a range
- Calculate class pass percentage

## Technologies
- Python
- NumPy

## Run
```bash
python analyzer.py
```

## NumPy Concepts
- Arrays
- Boolean indexing
- Filtering with conditions
- Logical AND
- Array statistics

## Learning Goal
Practice NumPy Boolean indexing through a practical student-data analysis project.
