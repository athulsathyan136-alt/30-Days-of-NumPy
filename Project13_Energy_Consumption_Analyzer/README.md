
# Project 13 - Energy Consumption Analyzer

## Description
An energy consumption analytics and anomaly detection
system built using Python and NumPy.

## Features
- Daily energy consumption analysis
- Average and median calculations
- Peak consumption detection
- Daily consumption changes
- Cumulative consumption
- Anomaly detection
- Percentile analysis
- Automatic CSV report generation

## NumPy Functions
genfromtxt, mean, median, std, sum, diff,
cumsum, where, argmax, argmin, percentile,
insert, column_stack, savetxt

## Technologies
- Python
- NumPy

## Installation
pip install -r requirements.txt

## Run
python main.py

## Output
outputs/energy_analysis.csv
