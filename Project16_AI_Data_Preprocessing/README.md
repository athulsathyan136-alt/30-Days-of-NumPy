
# Project 16 - AI Dataset Preprocessing

## Description
A machine-learning dataset preprocessing pipeline
built using Python and NumPy.

## Features
- Missing value handling
- Outlier detection using IQR
- Min-max normalization
- Standardization
- Categorical encoding
- Feature engineering
- Training and testing split
- Processed dataset export

## Technologies
- Python
- NumPy

## Installation
pip install -r requirements.txt

## Run
python main.py

## Outputs
- X_train.npy
- X_test.npy
- y_train.npy
- y_test.npy
- processed_features.csv

## Note
Educational project. A production pipeline should
fit preprocessing parameters on training data only.
