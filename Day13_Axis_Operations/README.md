# Day 13 — NumPy Axis Operations

## Overview
Learn how to perform calculations across rows and columns of 2D NumPy arrays.

## Topics
- Understanding rows and columns
- `axis=0` — column-wise results
- `axis=1` — row-wise results
- `np.sum()`
- `np.mean()`
- `np.max()`

## Files
- `axis_operations.py` — Examples
- `exercises.py` — Practice exercises

## Run
```bash
python axis_operations.py
python exercises.py
```

## Applications
Axis operations are useful for analyzing sales, student marks, business reports, and machine learning datasets.
