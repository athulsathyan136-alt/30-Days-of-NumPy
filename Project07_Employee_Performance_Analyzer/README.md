
# Project 07 - Employee Performance & Salary Analyzer

## Overview
A NumPy-based employee analytics project that analyses employee salaries, performance scores, attendance, and working hours.

## Features
- Employee statistics
- Salary analysis
- Performance classification
- Top performer identification
- Low attendance detection
- Employee performance ranking
- CSV report generation
- Text summary generation

## Technologies
- Python
- NumPy

## Project Structure
```text
Project07_Employee_Performance_Analyzer/
├── data/
│   └── employees.csv
├── outputs/
├── employee_analyzer.py
├── requirements.txt
└── README.md
```

## Installation
```bash
pip install -r requirements.txt
```

## Run
```bash
python employee_analyzer.py
```

## NumPy Concepts
- Arrays and indexing
- Statistical operations
- Boolean filtering
- Sorting
- Conditional selection
- File handling

## Learning Objective
Practise numerical data analysis using NumPy with a realistic employee dataset.
