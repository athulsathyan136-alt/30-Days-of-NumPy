# Day 27 – NumPy Index Finding and Searching

## Overview
A student performance ranking project using NumPy sorting, searching and index-finding operations.

## Concepts Covered
- `np.argmax()` – maximum value index
- `np.argmin()` – minimum value index
- `np.argsort()` – sorting indices
- `np.sort()` – sorting values
- `np.searchsorted()` – insertion positions
- `np.argpartition()` – partial sorting
