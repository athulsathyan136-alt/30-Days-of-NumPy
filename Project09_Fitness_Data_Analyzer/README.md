
# Project 09 – Fitness Data Analyzer

## Overview
A fitness data analysis project built using Python and NumPy.

It analyzes daily activity data, including steps, calories, sleep, water intake, and workout duration.

## Features
- Average daily steps
- Maximum and minimum steps
- Calories analysis
- Sleep analysis
- Fitness goal tracking
- Weekly performance summaries
- Correlation analysis
- Automatic report generation

## Technologies
- Python
- NumPy
- CSV

## How to Run

Install dependencies:

    python -m pip install -r requirements.txt

Run:

    python fitness_analyzer.py

## NumPy Concepts
- np.array()
- np.mean()
- np.max()
- np.min()
- np.argmax()
- np.argmin()
- np.sum()
- np.corrcoef()
- Boolean indexing
- Array slicing
