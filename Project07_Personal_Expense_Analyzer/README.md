
# Project 07 – Personal Expense Analyzer

## Overview
A beginner-friendly data analysis project built using Python and NumPy.

It analyzes personal expenses from a CSV dataset and generates category-wise summaries and a text report.

## Features
- Total and average expenses
- Median, maximum and minimum expenses
- Standard deviation
- Category-wise expense analysis
- Filtering expensive transactions
- Sorting expenses
- Automatic report generation

## Technologies
- Python
- NumPy
- CSV

## Project Structure
- data/: Expense dataset
- outputs/: Generated reports
- expense_analyzer.py: Main program
- requirements.txt: Dependencies

## How to Run

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run:

```bash
python expense_analyzer.py
```
