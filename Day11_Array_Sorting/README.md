
# Day 11 — NumPy Array Sorting

## Overview
Learn to sort one-dimensional and two-dimensional NumPy arrays.

## Topics
- `np.sort()`
- Ascending order
- Descending order
- Sorting student scores
- Sorting 2D arrays using `axis=1`
- Array slicing

## Files
- `sorting.py` — Sorting examples
- `exercises.py` — Practice exercises

## Run
```bash
python sorting.py
python exercises.py
```

## Applications
Sorting is useful for ranking scores, analyzing datasets,
finding low or high values, and preparing data for analysis.
