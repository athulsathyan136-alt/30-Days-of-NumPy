
# Project 08 – Student Performance Analyzer

## Overview
A student performance analysis project using Python and NumPy.

## Features
- Student average calculations
- Subject-wise analysis
- Pass and fail classification
- Grade assignment
- Top five student ranking
- Statistical analysis
- CSV and text report generation

## Technologies
- Python
- NumPy
- CSV

## How to Run

Install dependencies:

    python -m pip install -r requirements.txt

Run the project:

    python student_analyzer.py

## NumPy Concepts
- np.array()
- np.mean()
- np.max()
- np.min()
- np.median()
- np.std()
- np.argmax()
- np.argmin()
- np.argsort()
- Boolean indexing
- Array axis operations
