# Day 8 — NumPy 2D Indexing and Slicing

## Overview
This project demonstrates how to access, extract, and modify rows, columns, and sections of two-dimensional NumPy arrays.

## Topics Covered
- Accessing individual elements
- Selecting rows and columns
- Positive and negative indexing
- Slicing multiple rows
- Slicing multiple columns
- Extracting rectangular sections
- Modifying individual elements and rows
- Checking array properties

## Files
- `two_d_slicing.py` — Main examples
- `exercises.py` — Practice exercises

## How to Run
```bash
python two_d_slicing.py
python exercises.py
```

## Machine Learning Applications
Two-dimensional indexing and slicing help select rows, features, and subsets from tabular datasets during data preparation and analysis.
