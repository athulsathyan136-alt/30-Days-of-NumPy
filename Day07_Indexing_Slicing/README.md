# Day 7 — NumPy Indexing and Slicing

## Overview
This project demonstrates how to access, extract, and modify elements in NumPy arrays.

## Topics Covered
- Positive and negative indexing
- Array slicing
- Start, stop, and step
- Modifying array elements
- Two-dimensional array indexing
- Two-dimensional slicing
- Array properties

## Files
- `indexing_slicing.py` — Examples of indexing and slicing
- `exercises.py` — Practice exercises

## How to Run
```bash
python indexing_slicing.py
python exercises.py
```

## Applications in Machine Learning
Indexing and slicing are used to select features, extract rows and columns, prepare datasets, and inspect subsets of data.
