# Project 05 – Student Performance Analyzer

A Python and NumPy project that analyzes student academic performance across five subjects using a CSV dataset.

## Project Overview

This project analyzes marks, calculates student averages, identifies top performers, classifies grades, and compares study hours with academic scores.

**Dataset:** 30 students with synthetic educational data.

## Dataset Columns

| Column | Description |
|---|---|
| Student_ID | Unique student identifier |
| Name | Student name |
| Math | Mathematics marks |
| Science | Science marks |
| English | English marks |
| Computer | Computer marks |
| Social_Studies | Social Studies marks |
| Study_Hours | Daily study hours |

## Features

- Overall student performance statistics
- Subject-wise average, maximum and minimum marks
- Best and lowest performing subjects
- Pass/fail analysis
- Grade classification
- Grade distribution
- Top five student rankings
- Study-hours and marks correlation
- Performance percentiles
- CSV and text report generation
