# Day 25 – NumPy Missing Data Handling

## Overview
Learn how to detect, count, analyze, and replace missing values in NumPy arrays.

## Concepts Covered
- Detecting missing values with `np.isnan()`
- Counting missing values with `np.count_nonzero()`
- Calculating averages while ignoring missing values with `np.nanmean()`
- Replacing missing values with `np.where()`
- Understanding NaN (Not a Number)

## Key Learning

Missing values can affect calculations. NumPy provides functions such as `np.isnan()` and `np.nanmean()` to help identify and handle them.
