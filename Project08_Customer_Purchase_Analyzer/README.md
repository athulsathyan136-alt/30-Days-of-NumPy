
# Project 08 - Customer Purchase Behavior Analyzer

## Overview
A customer analytics project using NumPy to analyse purchasing behaviour, revenue, customer spending, and product categories.

## Features
- Total revenue calculation
- Customer spending analysis
- Top customer identification
- Product category analysis
- Monthly revenue analysis
- Customer ranking
- High-value purchase detection
- CSV and text reports

## Technologies
- Python
- NumPy

## Installation
pip install -r requirements.txt

## Run
python customer_analyzer.py

## Learning Outcomes
- NumPy arrays
- Boolean indexing
- Statistical analysis
- Aggregation
- Sorting and ranking
- Data export
