# Project 21 – Recurrent Neural Network From Scratch Using NumPy

## Overview
An educational Recurrent Neural Network implemented from scratch using NumPy for binary sequence classification.

## Features
- Synthetic sequential dataset
- Recurrent hidden states
- Tanh activation
- Softmax classification
- Cross-entropy loss
- Backpropagation Through Time (BPTT)
- Gradient clipping
- Gradient descent
- Test accuracy evaluation
- Model and prediction saving

## Architecture
- Input size: 1
- Hidden size: 8
- Output size: 2
- Sequence length: 5

## Technologies
- Python
- NumPy

## Run
```bash
python -m pip install -r requirements.txt
python main.py
```

## Learning Outcomes
Understand sequence processing, recurrent connections, hidden states, forward propagation, BPTT, and sequence classification.

## Limitations
This is a small educational RNN trained on synthetic data. It is not intended for production forecasting or language generation.
