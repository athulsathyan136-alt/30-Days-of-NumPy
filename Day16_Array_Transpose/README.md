# Day 16 — NumPy Array Transpose

## Overview
Learn how to transpose a NumPy array by switching its rows and columns.

## Topics
- Array transpose using `.T`
- `np.transpose()`
- Understanding array shapes
- Rows and columns in 2D arrays

## Files
- `transpose.py` — Transpose examples
- `exercises.py` — Practice exercises

## Run
```bash
python transpose.py
python exercises.py
```

## Applications
Transposing arrays is useful in data analysis, matrix operations, and machine learning.
